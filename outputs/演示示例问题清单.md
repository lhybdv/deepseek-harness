# Meteo 演示 · 示例问题清单

> 用途：演示/验收时按图索骥地提问。每条都标注了它考的是哪条链路、以及期望的回答形态。
>
> 演示前请先上传语料：把 `inputs/corpus/` 下的 6 个 `.md` 一起拖到「语料库」页，点「索引」。
> 语料类问题（第五、六组）必须先做这一步，否则命中的是空的/旧的语料。

## 0. 这份演示当前覆盖什么

| 维度 | 实际发布的数据 |
|---|---|
| 站点 | **24 个乡镇级自动站**，全在河南省：新乡县 8、滑县 8、永城市 8 |
| 要素 | 气温 `temperature`、相对湿度 `humidity`、降水量 `precipitation`、风速 `windSpeed`、土壤相对湿度 `soilMoisture` |
| 作物 | **冬小麦**、**夏玉米** |
| 生育期 | 冬小麦：播种 / 越冬 / 返青 / 拔节 / 抽穗 / 灌浆 / 收获；夏玉米：播种 / 苗期 / 拔节 / 抽雄 / 灌浆 / 收获 |
| 灾害 | **暴雨、干旱、晚霜冻、大风**（分级 low/medium/high，按发布阈值 + 持续时长判定） |
| 实况时间 | 2026-09-23 起逐小时；预报从 2026-09-24 起 |
| 语料 | 东北（黑龙江）大豆/水稻/玉米/黑土地保护性耕作共 6 篇，与上面的站点数据**不是同一地区** |
| 输入方式 | 文字；图片（已开启该模型的多模态声明，可传截图/图提问）；语音**未实现** |

站点速查（提问时用乡镇名最自然）：

- 新乡县：城关镇、翟坡镇、小冀镇、朗公庙镇、古固寨镇、七里营镇、大块镇、陆村乡
- 滑县：道口镇、白道口镇、留固镇、上官镇、牛屯镇、瓦岗寨乡、慈周寨镇、老店镇
- 永城市：芒山镇、高庄镇、条河镇、裴桥镇、马牧镇、刘河镇、新桥镇、陈集镇

## 一、实况与预报（考 `meteo_station_lookup` / `meteo_consult` 的 observation、forecast 步骤）

| # | 示例问题 | 期望回答要点 |
|---|---|---|
| 1.1 | 城关镇现在气温多少？ | 给出乡镇名对应站点、当前气温，若数据有范围则带上时间 |
| 1.2 | 滑县道口镇过去 24 小时下了多少雨？ | 降水量累计 + 时间窗口 |
| 1.3 | 永城芒山镇现在的风速和土壤湿度是多少？ | 两个要素分别给出，带单位 |
| 1.4 | 新乡县各乡镇目前墒情怎么样？ | 会先让你选具体乡镇（一个县下有 8 个站） |
| 1.5 | 翟坡镇未来两天天气怎么样？ | 预报逐时/分段摘要，给出预报时段 |
| 1.6 | 道口镇明天会下雨吗？ | 预报降水 + 时段；无降水则明确说无 |
| 1.7 | 芒山镇最近的气温、湿度、风速实况 | 多要素实况 |
| 1.8 | 城关镇和道口镇哪个更热？（对比类） | 两个站点的实况对比，需分别给出 |
| 1.9 | 今天永城适合晾晒吗？ | 结合降水/湿度/风速给出判断，并说明依据要素 |

> 提"新乡县/滑县/永城市"这种**县级**说法时，工具往往会先返回候选站点让你确认——这正是设计行为（避免猜错站）。

## 二、农事活动适宜性（考 `meteo_consult` 的 suitability 步骤 + 作物日历）

| # | 示例问题 | 期望回答要点 |
|---|---|---|
| 2.1 | 永城芒山镇的夏玉米现在适合收获吗？ | 判定"适宜/不适宜/未知" + 触发的判据（风、雨）+ 覆盖的日期窗口 |
| 2.2 | 滑县道口镇的冬小麦现在能播种吗？ | 若不在 10-15~10-25 窗口内，应说明"没有已发布的窗口覆盖这些天"，而不是编一个结论 |
| 2.3 | 城关镇的夏玉米灌浆期有没有干旱风险？ | 干旱判据 + 是否成立 + 持续小时数 |
| 2.4 | 未来三天适合收玉米吗？ | 逐日适宜性 + 判据 |
| 2.5 | 现在给冬小麦播种合不合适？ | 同 2.2；窗口未到要如实说 |
| 2.6 | 这周末能不能打药？（施药类） | 若发布数据里没有该活动的窗口/判据，应说明数据未覆盖，而非硬答 |

> 适宜性一定是**按天 + 按作物/活动窗口**给的，"适宜"必须带时间窗口；窗口外的诚实回答是演示的加分项。

## 三、灾害风险定级（考 `meteo_consult` 的 hazard 步骤 + 发布阈值）

| # | 示例问题 | 期望回答要点 |
|---|---|---|
| 3.1 | 新乡县未来有没有暴雨风险？ | 暴雨等级 low/medium/high + 触发阈值（如 ≥25mm/12h 或 24h）+ 起始时间 |
| 3.2 | 滑县这几天会不会干旱？ | 土壤湿度阈值判据是否持续成立 |
| 3.3 | 永城有没有晚霜冻风险？ | 若气温阈值未命中，应报 `unknown`（"没有已发布判据成立"），不臆造等级 |
| 3.4 | 未来两天有大风吗？对玉米收获有什么影响？ | 风速阈值 + 持续时长 + 与收获窗口的关系 |
| 3.5 | 芒山镇墒情会不会影响出苗？ | 土壤湿度 + 干旱判据 |
| 3.6 | 给城关镇做个灾害风险研判 | 综合 4 类灾害的定级 + 依据 |

> 每个等级都要能说出**是哪条判据、持续了多久、从什么时候开始**；`unknown` 是合法且正确的答案。

## 七、演示脚本建议（3 分钟版）

1. **实况+预报**：问 1.1、1.5 —— 展示数据接入与站点定位。
2. **适宜性+灾害**：问 2.1、3.1 —— 展示判据、等级、时间窗口。
3. **多轮**：接上面追问「那明天呢？」—— 展示上下文继承。
4. **语料**：上传 6 篇后问 5.1.1、5.2.1 —— 展示检索、引用与"不串档"。
5. **诚实边界**：问 5.4.1 或 6.2 —— 展示"没有依据就说没有"。
6. （可选）**多模态**：传一张图提问 —— 展示图片输入。

## 附：提问小贴士

- 用**乡镇名**（如"城关镇""芒山镇"）比用县名更顺，县名会触发候选澄清。
- 想考"不许编"就挑 **5.4 / 第六组**；想考"引用准确"就挑 **5.2**。
- 语料问题先确认「语料库」页里那 6 篇都在、且是本次索引后的列表。
- "适宜/风险"类回答一定跟着时间窗口；只有一句结论没窗口的，可以当场追问"哪几天"。
