> 用途：演示/验收时按图索骥地提问。每条都标注了它考的是哪条链路、以及期望的回答形态。

## 一、实况与预报（考 `meteo_station_lookup` / `meteo_consult` 的 observation、forecast 步骤）

| # | 示例问题 | 期望回答要点 |
|---|---|---|
| 1.1 | 五常镇现在气温多少？ | 给出乡镇名对应站点、当前气温，若数据有范围则带上时间 |
| 1.2 | 榆树市五棵树镇过去 24 小时下了多少雨？ | 降水量累计 + 时间窗口 |
| 1.3 | 昌图镇现在的风速和土壤湿度是多少？ | 两个要素分别给出，带单位 |
| 1.4 | 五常市各乡镇目前墒情怎么样？ | 会先让你选具体乡镇（一个县级市下有 8 个站） |
| 1.5 | 拉林满族镇未来两天天气怎么样？ | 预报逐时/分段摘要，给出预报时段 |
| 1.6 | 五棵树镇明天会下雨吗？ | 预报降水 + 时段；无降水则明确说无 |
| 1.7 | 昌图镇最近的气温、湿度、风速实况 | 多要素实况 |
| 1.8 | 五常镇和五棵树镇哪个更热？（对比类） | 两个站点的实况对比，需分别给出 |
| 1.9 | 今天昌图县适合晾晒吗？ | 结合降水/湿度/风速给出判断，并说明依据要素 |

> 三个县级农业示范区的县市名以及哈尔滨、长春、沈阳的城市名都可直接定位到各自首个已发布站点；如果地点确实未覆盖，工具返回覆盖范围和已发布的县城站点。不要要求用户提供站号，也不要编造最近站或数据。

## 二、农事活动适宜性（考 `meteo_consult` 的 suitability 步骤 + 作物日历）

| # | 示例问题 | 期望回答要点 |
|---|---|---|
| 2.1 | 昌图镇的玉米现在适合收获吗？ | 判定"适宜/不适宜/未知" + 触发的判据（初霜、风、雨）+ 覆盖的日期窗口 |
| 2.2 | 五常镇的大豆现在能播种吗？ | 若不在 05-01~05-20 窗口内，应说明"没有已发布的窗口覆盖这些天"，而不是编一个结论 |
| 2.3 | 榆树市弓棚镇的玉米抽雄吐丝期有没有低温冷害风险？ | 低温冷害判据 + 是否成立 + 持续小时数 |
| 2.4 | 未来三天适合收玉米吗？ | 逐日适宜性 + 判据 |
| 2.5 | 现在给水稻插秧合不合适？ | 按 05-10~05-30 窗口如实回答 |
| 2.6 | 这周末能不能打药？（施药类） | 若发布数据里没有该活动的窗口/判据，应说明数据未覆盖，而非硬答 |

> 适宜性一定是**按天 + 按作物/活动窗口**给的，"适宜"必须带时间窗口；窗口外的诚实回答是演示的加分项。

## 三、灾害风险定级（考 `meteo_consult` 的 hazard 步骤 + 发布阈值）

| # | 示例问题 | 期望回答要点 |
|---|---|---|
| 3.1 | 五常市未来有没有暴雨风险？ | 暴雨等级 low/medium/high + 触发阈值（如 ≥25mm/12h 或 24h）+ 起始时间 |
| 3.2 | 榆树市这几天会不会有春旱？ | 土壤湿度阈值判据是否持续成立 |
| 3.3 | 昌图县有没有初霜风险？ | 若气温阈值未命中，应报 `unknown`（"没有已发布判据成立"），不臆造等级 |
| 3.4 | 未来两天有大风吗？对玉米收获有什么影响？ | 风速阈值 + 持续时长 + 与收获窗口的关系 |
| 3.5 | 五常镇墒情会不会影响玉米播种？ | 土壤湿度 + 春旱判据 |
| 3.6 | 给昌图镇做个东北农业气象风险研判 | 综合发布灾害判据的定级 + 依据 |

> 每个等级都要能说出**是哪条判据、持续了多久、从什么时候开始**；`unknown` 是合法且正确的答案。

## 七、演示脚本建议（3 分钟版）

1. **实况+预报**：问 1.1、1.5 —— 展示数据接入与站点定位。
2. **适宜性+灾害**：问 2.1、3.1 —— 展示判据、等级、时间窗口。
3. **多轮**：接上面追问「那明天呢？」—— 展示上下文继承。
4. **语料**：上传 6 篇后问 5.1.1、5.2.1 —— 展示检索、引用与"不串档"。
5. **诚实边界**：问 5.4.1 或 6.2 —— 展示"没有依据就说没有"。
6. （可选）**多模态**：传一张图提问 —— 展示图片输入。

## 附：提问小贴士

- 用乡镇或城市站点名（如“五常镇”“哈尔滨市”）都能定位；县级名会使用其首个已发布站点，不必先选乡镇。
- 想考"不许编"就挑 **5.4 / 第六组**；想考"引用准确"就挑 **5.2**。
- 语料问题先确认「语料库」页里那 6 篇都在、且是本次索引后的列表。
- "适宜/风险"类回答一定跟着时间窗口；只有一句结论没窗口的，可以当场追问"哪几天"。
