## 一、原始需求（文字版）

> 4. 投标人现场演示基于智能体的多模态人机交互智能应答。基于智能体的多模态人机交互智能应答演示各类相关实况监测预报数据，针对乡镇级点位的灾害及农事活动适宜性问答，并基于专业语料库给出综合研判。基于智能体的灾害预警产品智能生成与灾害风险智能识别效果。演示区划产品图像全自动识别分类、核心特征提取与语义转化功能；展示不少于两张同类型普查区划图像对比、差异研判及可视化成果。自动或手动生成气象文档产品，展示数据自动填充、专业内容优化能力。完整提供文档在线编 - 审 - 发 - 存全流程。支持文字、语音两种输入方式，完成口语化提问语义识别、上下文多轮对话。调用农业气象知识内容，面向用户自动输出相应灾害咨询、农事建议等问答结果。

## 五、已确认决策与待确认事项（与需求相关）

**已确认**

1. **默认语言 = 中文**：UI 已实现（`packages/client/locale`）——新增 `DEFAULT_LOCALE = 'zh'` 作为“无可用信号”时的打开默认，浏览器明确请求 zh/en 时仍按其解析，`FALLBACK_LOCALE = 'en'` 仅保留为字典回退终点，设置仍可在“设置 → 通用 → 语言”切换；模型回答语言仍无设置项，待新增（默认中文、跟随语言设置）。
2. **语料检索 = 语义检索**：本需求要求「基于专业语料库给出综合研判」，检索必须是语义检索。当前为词法（BM25 + 中文 bigram），不满足 → R2.4 转为「未满足」，需新增 embedding + 向量召回。
3. **语音输入 = 讯飞 RTASR 云端识别**：参照 `D:\01-项目\shandong-chat` 的实现（`src/services/rtasr-browser.ts`：HMAC-SHA1 签名 WebSocket、1280 B/40 ms PCM 帧；凭证与端点见其 `src/global-config.ts`），在既有语音接缝上新增 Host 侧 Provider `packages/experimental/speech-to-text-rtasr`。语音栈仍由可选 Bundle `voice-input-bundle` 组合（符合「实验性能力以可选 Bundle 提供」的既定策略），Bundle 随附该 Provider 行且默认关闭；演示 overlay 用 `- id` 补丁启用该行并选择 `iflytek-rtasr`。签名与帧投递在 Host 侧完成，密钥不出现在浏览器；本地 SenseVoice Provider 保留，识别器与语言可在 Bundle 详情中切换。

**待确认**

1. **区划图像部分**：需求 4 中 R4 整组在现有代码中没有任何对应实现，需要确认是自行开发还是集成既有模型/服务。
